# Icon
Icon, genellikle eylemi veya bir amacı tanımlamak için kullanılan görsel göstergelerdir. 
Bu bileşen react-native-vector-icons paket bileşeni olan “Icon” bileşeni kullanılarak geliştirilmiştir.

![Tux](../images/icon.png)

## Usage

``` js
import { Icon } from 'react-native-pinecone';

<Icon name="github" />

<Icon name="gitlab" color="red" />

<Icon name="facebook" color="blue" size={50} />

<Icon name="gitlab" type="AntDesign" color="red" />
```
